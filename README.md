# DARKHANTECH — V29 для GitHub Pages

Актуальная сборка на 26.11.2026, основана на V28. Включены согласованные правки главной, весь каталог, страницы оборудования, фотографии и видео.

## Развёртывание

1. Создайте резервную копию текущего репозитория и убедитесь, что конфликтующий merge в GitHub Desktop отменён.
2. Распакуйте архив. Скопируйте **содержимое архива**, а не внешнюю папку: файл `index.html` должен оказаться в корне репозитория.
3. Если локальная ветка разошлась с GitHub, сначала аккуратно синхронизируйте историю и только потом делайте commit/push. Не используйте force push без проверки.
4. В GitHub Pages выберите ветку main и каталог /(root). После обновления проверьте сайт на компьютере и смартфоне, обновляя страницу без кэша.

## Что уже подготовлено

- Согласованный первый экран и шесть направлений с приоритетом фасовки и упаковки.
- Блок рекомендуемого оборудования со ссылкой в каталог (конкретные 15–20 моделей будут добавлены после получения списка).
- 6 преимуществ DARKHANTECH, видео Xuzhong, 6 этапов работы, гарантия и сервис.
- 90 HTML-страниц и локальные медиа. Все формы сайта подготовлены для HTTPS-обработчика CRM.

## Что НЕ подключено автоматически

- **Живая отправка заявок в Битрикс24 не активна.** В `site-config.js` значение `window.DH_LEAD_ENDPOINT` пустое; до подключения защищённого серверного обработчика формы предлагают скопировать обращение, а не обещают отправку.
- GitHub Pages не поддерживает PHP. Серверный обработчик и секретный вебхук Битрикс24 разворачиваются на отдельном HTTPS-хостинге; не публикуйте токены в GitHub.
- Номера Mango и ссылки WhatsApp/Telegram добавляются в `site-config.js` только после подтверждения и проверки работы соответствующих сервисов.
- Для Яндекс Метрики требуется подтверждённый ID.
- Требуются материалы от клиента: 15–20 выбранных моделей, пояснения к видео Xuzhong и данные по посещённым заводам.

## Проверки

Проверены локальные ссылки и якоря HTML, читаемость изображений, JSON-LD, синтаксис JavaScript и CSS, целостность ZIP. Проверка реального отображения через локальный Chromium заблокирована ограничениями среды, поэтому перед запуском рекламы нужен ручной визуальный и функциональный тест на опубликованном сайте.
