# DARKHANTECH — сайт V18, версия для GitHub Pages

Исходная сборка: **V18 CLEAN CATALOG FULL SITE**, 24.11.2026.
Статус: **демонстрация сайта и каталога**. Для полноценного коммерческого запуска ещё нужны домен, хостинг и интеграция заявок.

## Публикация на GitHub Pages

1. Откройте репозиторий `ahatsmmalin-ai/darkhantech` в GitHub Desktop (или клонируйте его через Git).
2. Из этого архива скопируйте **все файлы и папки непосредственно в корень репозитория**, включая `.nojekyll`. Не загружайте сам ZIP как один файл.
3. Создайте коммит, например `DARKHANTECH V18 — clean catalog`, и нажмите **Push origin**.
4. В GitHub откройте **Settings → Pages**. Выберите **Deploy from a branch**, ветку `main`, папку `/(root)` и сохраните.
5. После публикации сайт должен открываться по адресу: https://ahatsmmalin-ai.github.io/darkhantech/

**Важно:** в ZIP более 100 файлов; удобнее загрузить через GitHub Desktop, чем пытаться перенести всё через веб-форму GitHub.

## Что настроено

- Главная (`index.html`) и остальные HTML-страницы лежат в корне.
- Все изображения, локальные видео, JS и CSS сохранены со своими относительными путями.
- Добавлены `.nojekyll`, `sitemap.xml` и актуальный `robots.txt` для GitHub Pages.
- Форма заявки на GitHub **не отправляется в CRM**: пока можно только скопировать текст обращения.
- В `site-config.js` пока нет рабочего номера, ссылок мессенджеров и адреса приёма заявок.
- Секретного вебхука Bitrix24 в публичном репозитории быть не должно.

## После покупки домена и хостинга

1. Развернуть серверный HTTPS-обработчик заявок, связать его с Bitrix24, проверить создание лидов и уведомления.
2. В `site-config.js` заполнить `window.DH_LEAD_ENDPOINT` публичным URL обработчика, не секретным вебхуком Bitrix24.
3. После подключения Mango Office заполнить `window.DH_CONTACTS` актуальными проверенными контактами.
4. Добавить номер счётчика в `window.DH_METRIKA_ID`, проверить цель `lead_sent` и корректную UTM-разметку.
5. Обновить адреса `canonical`, Open Graph, JSON-LD, sitemap.xml, robots.txt со ссылок GitHub Pages на домен.
6. Проверить политику персональных данных, условия согласия, уведомления, защиту от спама, мобильную версию и тестовые заявки.

## Примечание о контенте

Устаревшие текстовые инструкции из исходного архива не публикуются. Шаблон запроса для поставщика сохраняется, поскольку на него ссылается раздел Sourcing. Сам сайт, каталог и мультимедиа сохранены.
