# DARKHANTECH — V25 для GitHub Pages

Полная сборка сайта с согласованными на 25.11.2026 правками (V25).

## Загрузка

1. Распакуйте архив. **Загружайте содержимое**, не папку и не ZIP целиком. Файл `index.html` должен быть в корне репозитория.
2. Если GitHub Desktop сообщает о конфликтующем слиянии, сначала `Abort merge`; этот архив не разрешает конфликты автоматически. Сохраните свои локальные изменения перед заменой.
3. Синхронизируйте ветку с удалённым репозиторием, затем замените файлы сайта новой сборкой. Сделайте Commit и Push. Не используйте Force Push без проверки истории.
4. GitHub Pages: main / (root).
