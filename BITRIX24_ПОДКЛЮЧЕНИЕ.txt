DARKHANTECH — подключение сайта к Битрикс24 (V29)

Статус: интеграция подготовлена, но НЕ включена. Фактической доставки лидов не подтверждено.

1. Разместите HTTPS backend из отдельного пакета DARKHANTECH_V28_BITRIX24_BACKEND.zip на сервере с PHP.
2. Создайте входящий вебхук Битрикс24 с минимально необходимыми правами на создание лидов и сохраните секрет только на сервере.
3. Настройте на сервере URL вебхука, CORS для фактического домена и соответствие ID источников (справочник CRM).
4. После проверки backend укажите ПУБЛИЧНЫЙ HTTPS адрес обработчика в window.DH_LEAD_ENDPOINT в site-config.js и заново разверните сайт.
5. Проверьте тестовой заявкой: создание лида со стадией «Новый лид», контактные данные, товар, страница, UTM и ответственный; отдельно проверьте отказ при ошибках API и повторы отправок.
6. Никогда не размещайте ключи и URL входящего вебхука Bitrix24 в публичном JavaScript или GitHub.

До завершения шагов кнопка формы предлагает скопировать обращение. Не запускать платный трафик без проверки доставки заявок.
