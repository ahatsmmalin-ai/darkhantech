Интеграция заявок (подготовлена, но НЕ включена):
- В site-config.js поле window.DH_LEAD_ENDPOINT оставлено пустым. Пока оно пустое, форма скачивает черновик заявки локально — это не отправка лида.
- После разработки защищённого обработчика (HTTPS, CORS для домена сайта, защита от спама, хранение секретов на сервере) укажите публичный URL обработчика в site-config.js.
- Передаваться будет FormData вместе с выбранными файлами. Обработчик должен возвращать HTTP 2xx только при успешной записи заявки, иначе сайт покажет ошибку.
- Вебхук Bitrix24 и другие секреты нельзя указывать напрямую в site-config.js.
- После успешной отправки (не после скачивания TXT) будет вызвана цель «lead_sent», если на сайте загружена Яндекс Метрика и указан window.DH_METRIKA_ID. Сам счётчик не установлен.
