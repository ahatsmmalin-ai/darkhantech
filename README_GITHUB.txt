DARKHANTECH · версия для предварительного согласования по аудиту от 07.11.2026

КОМПЛЕКТ
- index.html — главная
- about.html — философия и основательницы
- industrial.html — направления, два черновых разбора из аудита, сравнение конфигураций, калькулятор, структура стоимости
- expeditions.html — экспедиции
- sourcing.html — проверка и поиск поставщиков
- site.css, site.js, изображения, favicon.svg — необходимые ресурсы

КАК ОБНОВИТЬ GITHUB PAGES
1. Распакуйте ZIP.
2. Загрузите все файлы из папки в корень ветки main вашего репозитория GitHub.
3. Замените файлы с совпадающими именами, добавьте отсутствующие.
4. В Settings → Pages: Deploy from a branch → main → /(root).
5. После публикации обновите страницу с очисткой кэша (Ctrl+F5).

ВЕРСИЯ ДЛЯ СОГЛАСОВАНИЯ, НЕ ДЛЯ СБОРА ЗАЯВОК
В форме можно выбрать до 3 вложений до 20 МБ и скачать черновик заявки в TXT. Вложения НЕ отправляются и НЕ записываются на сервер, их содержимое не входит в TXT. Действующая отправка через CRM/почту требует отдельного подключения и настройки хранения персональных данных.

ВАЖНО О СОДЕРЖАНИИ
- Сведения об основательницах взяты из маркетингового аудита и подлежат подтверждению.
- Два разбора — черновые, обезличенные интерпретации задач, описанных в аудите; не завершённые клиентские кейсы.
- Сравнения и калькулятор — модельные примеры. Не обещают результатов.
- Визуалы пищевых производств иллюстративные, не заявлены как кадры собственных визитов.

ДОПОЛНИТЕЛЬНО ПОТРЕБУЕТСЯ ОТ КЛИЕНТКИ
1. Портреты Эржены и Юмжаны и подтверждение биографий, история появления бренда.
2. Собственные фото и видео посещений китайских заводов и разрешения на публикацию.
3. Подтверждённые факты по производственным запросам (в том числе задачи, упомянутые в аудите) и разрешение на публикацию.
4. Подтверждённые факты о составе сервиса и распределении ответственности с партнёрами.
5. Канал для настоящей отправки заявок, политика обработки персональных данных и порядок работы с загружаемыми файлами.
